# Funktionsvergleich

Öffentliche Funktionsreferenz: [deutsche Choreographic-App-Store-Seite](https://apps.apple.com/de/app/choreographic-tanzformationen/id1608391996), abgerufen am 16.10.2026. Keine bezahlten Funktionen selbst getestet; die Free/Pro-Zuordnung einzelner Funktionen ist unklar. Keine fremden Assets oder Quelltexte übernommen.

| Bereich | Öffentlich beschrieben | ChoreoFlow-Arbeitsstand |
| --- | --- | --- |
| Formationen/Vorlagen | Presets, eigene Anordnungen | Neun geometrische Formen; eigene Bibliothek noch offen |
| Individuelle Wege | Kurven, Bögen, Mehrpunktwege | Kern vorhanden, Bogen-/Geraden-UI; direkte Kontrollpunkte fehlen |
| Gruppen/Besetzungen | Wiederverwendbare Crews, Farbauswahl | Lokale Besetzungen, Mehrfachauswahl, starre Drehungen |
| 3D | Vorschau, Perspektiven | Gemeinsame Szene, drei Kameras; iPhone ungetestet |
| Musik/Timing | Musiksynchronisierung, genaue Zeiten | Sekunden/Counts, persistenter lokaler Clip, Schnitt/Versatz/Blenden; Mehrclipbearbeitung offen |
| Offline | Bearbeiten und später synchronisieren | Lokale Persistenz; bewusste Cloudkopie, kein Team-Merge |
| Zusammenarbeit | Echtzeitbearbeitung | Rechte/CAS-Unterbau, komplette Oberfläche fehlt |
| Ordnerrechte | Anzeigen/Bearbeiten pro Ordner | Noch nicht implementiert |
| Requisiten | Bühnenobjekte und Animation | Datenmodell/Konfliktkern; Editor fehlt |
| Wiederverwendung | Crews und Formationen | Besetzungen und Projektdateien |
| Weitergabe | Teamzugriff | Unveränderliche Zuschauerstände, widerrufbare Links |

Diese Tabelle ist ein Entwicklungsvergleich, keine behauptete Funktionsparität.
